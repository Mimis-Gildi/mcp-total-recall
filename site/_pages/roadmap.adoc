== Phase 1: Real Architect Review and Ops -- v2.0.0-v5.x.x

ToDo: document this after fixing architecture.

*IMPORTANT:* *_Cockburn's Hexagonal Architecture (HA) is NOT USED here (antipattern)!_*

"Hexagon-Like" is a widely useful paradigm that segregates +
a) shape-face per single concern; +
b) plants an Anticorruption Layer (ACL) component on a face. +
The most improper part of HA, also known as Ports and Adapters, is input vs. output ports. +
_We acknowledge Alistair's contribution for an attempt to decouple business. -- *that's all*!_
